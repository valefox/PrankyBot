# PrankyBot
Diddy Bot, but with the corny "Diddy" branding removed.

## PrankyBot Installation
> Note that "PrankyBot" does not currently have an active discord bot. However, you can follow these steps to install the old "Diddy Bot"
1. Open Discord
2. Navigate to the App Directory in User Settings
3. Search for `Diddy Bot`
4. Once you have located Diddy Bot, click `Add App`
5. Choose to `Add to Server` Or `Add to apps`, depending on what you would like to do

PrankyBot does not have any active support server.
